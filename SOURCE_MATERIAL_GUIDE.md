# ECE Graduate Program source-material guide

Put source documents in the local `source_material/` directory. That directory is
excluded from Git, so its contents will not be committed to this repository.

## Suggested organization

```text
source_material/
  01_admissions_and_deadlines/
  02_programs_and_tracks/
  03_program_requirements/
  04_abm/
  05_plan_of_study/
  06_funding_and_assistantships/
  07_registration_and_advising/
  08_milestones_and_graduation/
  09_forms_and_contacts/
  10_existing_web_pages/
  11_frequently_asked_questions/
  12_style_branding_and_assets/
```

You do not need to rename every file. Clear filenames help, but preserving the
official filename and date is often useful. If two sources disagree, do not
silently reconcile them; add a short note describing which source is current.

## Useful materials

- Official graduate-school and ECE handbooks, catalogs, policies, and forms
- Application instructions, prerequisites, fees, and domestic/international deadlines
- Requirements for every degree, concentration, thesis, and non-thesis option
- ABM eligibility, application process, course sharing, timelines, and examples
- Plan-of-study rules, blank forms, completed fictional examples, and approval workflow
- Funding, tuition, assistantship, fellowship, and renewal information
- Registration, advising, transfer-credit, leaves, probation, and exception policies
- Milestones: committees, proposals, exams, defenses, dissertation/thesis submission,
  graduation applications, and commencement
- Contact lists with the role responsible for each question
- Existing URI webpages, or a text file containing their URLs
- Repeated student questions and the answers normally given
- URI/ECE brand guidance, approved logos, photos, and accessibility requirements

PDF, DOCX, XLSX, PPTX, HTML, Markdown, plain text, images, and saved email text are all
acceptable. Native/editable versions are preferable to scans. For a webpage, a URL
in a `.txt` or `.md` file is enough unless the page is restricted or likely to change.

## Add context where needed

For documents whose status is not obvious, add a nearby text file or a central
`NOTES.md` stating:

- whether the document is official, a draft, or an informal explanation;
- who owns or approves the information;
- the effective term or last-known update date;
- whether it applies to MS, PhD, ABM, or a particular track;
- known conflicts, exceptions, or upcoming changes; and
- whether it is suitable for publication or only for background.

## Privacy and publishing safety

Do not include identifiable student records, grades, student IDs, application files,
recommendation letters, disability information, disciplinary information, or private
email threads. Convert real cases into anonymous question-and-answer examples and
remove names, contact details, dates, IDs, and any unusual facts that could identify
a student.

Placing a file in this ignored directory prevents accidental Git commits, but it does
not by itself authorize publication. Content intended only as background should be
marked clearly.
